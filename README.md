🌍 Geography MCQs Quiz
A simple yet engaging Geography Multiple-Choice Quiz designed to test and enhance your knowledge of geography.
Answer questions, receive instant feedback, and challenge yourself to see how far you can go!

🚀 Features
🎯 Multiple-choice geography questions
🔊 Sound effects for clicks, correct, and incorrect answers
⏭️ Instant feedback and a "Try Again" feature
❌ Game over upon the first incorrect answer, making it a serious challenge

🎮 How to Play
Click the Start Game button to begin.
Read each geography question and select an answer.
Click Submit to check your answer.
If correct, click Next to proceed.
If incorrect, the game ends immediately. Click Try Again to restart.

🛠️ Technologies Used
HTML – For structuring the quiz
CSS – For styling the UI
JavaScript – For game logic and interactivity
